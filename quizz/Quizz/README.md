# Desafio EAC — Aprender, Jogar e Evoluir

Jogo educativo em HTML, CSS e JavaScript para o Estarreja Andebol Clube.

## Estrutura

- `index.html` — estrutura da aplicação.
- `styles.css` — identidade visual e responsividade.
- `app.js` — lógica do jogo, pontuação, cronómetro, ajudas e estatísticas.
- `questions.js` — banco de 50 perguntas, separado da lógica para facilitar futuras atualizações.
- `assets/emblema-eac.png` — emblema fornecido pelo clube.
- `assets/emblema-eac-original.jpg` — cópia original do ficheiro fornecido.

## Como publicar no GitHub Pages

1. Coloca estes ficheiros na raiz do repositório.
2. Confirma que `index.html` está na raiz.
3. No GitHub, abre **Settings → Pages**.
4. Em **Build and deployment**, seleciona **Deploy from a branch**.
5. Seleciona a branch principal e a pasta `/ (root)`.
6. Guarda e aguarda a publicação.

O projeto não usa bibliotecas externas, servidor, base de dados ou chamadas à Internet. Pode funcionar diretamente como ficheiro local e no GitHub Pages.

As perguntas são redação original baseada no **Livro de Regras de Jogo de Andebol — edição de 1 de julho de 2025**, disponibilizado pela Federação de Andebol de Portugal, e nas regras IHF correspondentes.

Nota: as representações dos sinais do árbitro dentro do jogo são pictogramas educativos próprios; não são reproduções dos desenhos oficiais da IHF.
